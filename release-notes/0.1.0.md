# CueFlow 0.1.0

The first official signed release of CueFlow, an offline teleprompter and camera for Android 10 and later.

- Automatic camera capability discovery, including exposed physical lenses and recording modes omitted from standard metadata.
- 4K recording capped at 30 fps; 2K, 1080p, and 720p up to 60 fps when supported. Extra modes are checked using actual encoded frames.
- Offline English speech following with the bundled Zipformer model, plus optional Whisper model import.
- Portrait and landscape recording, script management, camera zoom, white balance, and recording-folder selection.
- Clean saved videos without the teleprompter overlay, using H.264 or HEVC video and AAC audio.

The universal APK includes ARM64, ARMv7, and x86-64 support. A SHA-256 checksum is provided alongside it.

This release uses a dedicated signing certificate. Earlier debug/preview installations use a different certificate, so Android cannot update them in place. Save any scripts or settings you need before removing a debug/preview installation. Subsequent official releases will use the same release certificate for normal updates.

Validation includes 28 unit tests, camera-discovery restart checks, and Moto Edge 60 Fusion recordings at front 4K30, rear 4K30, and rear 1080p60. Camera-mode availability remains dependent on the device's accessible camera capabilities.
